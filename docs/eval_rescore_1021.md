## C-2. 답할 수 없는 질문을 인용·문맥 지표에서 제외

기대 행동이 보류·거절·되묻기인 58문항(제공 30, 팀 28)은 올바르게 응답해도 인용이 없어서 인용 지표가 깎인다. 이를 빼고 답할 수 있는 212문항만으로 다시 계산했다.

| 지표 | 기본 RAG 전체 270 → 답할 수 있는 212 | Multi-Agent 270 → 212 |
|---|---|---|
| 인용 Hit (전체) | 0.885 → **0.948** | 0.960 → **0.995** |
| 인용 Hit (**팀 골든셋**) | 0.772 → **0.952** | 0.899 → **1.000** |
| 인용 Hit (제공 골든셋) | 0.946 → 0.946 | 0.993 → 0.993 |
| 인용 Recall (전체) | 0.810 → 0.867 | 0.882 → 0.913 |
| 인용 Recall (팀 골든셋) | 0.738 → 0.914 | 0.861 → 0.962 |
| 문맥 Recall (전체) | 0.916 → 0.920 | 0.935 → 0.936 |

- **팀 골든셋의 낮은 인용 점수는 거의 전부 측정 방식의 문제였다.** 답할 수 있는 팀 문항만 보면 Multi-Agent 인용 Hit는 1.000이다. 제공 골든셋은 보류 문항에 근거 ID가 비어 있어 영향이 없다.
- 이 보정은 한계점 3번(README)에 해당한다. 앞으로 인용·문맥 지표는 "답할 수 있는 문항 기준"을 함께 보고한다.

## C-3. 응답 유형 라벨 정리

| 지표 | 기본 RAG | Multi-Agent |
|---|---:|---:|
| 엄격 (기대한 유형과 정확히 같음) | 0.730 | 0.830 |
| 완화 (허용 유형이면 통과) | 0.941 | 0.959 |
| `answer`·`correct` 통합 | 0.941 | 0.959 |

- 완화 기준은 이미 `answer`와 `correct`를 서로 허용 유형으로 보므로 통합 기준과 값이 같다. 엄격과 완화의 차이(기본 0.21, MA 0.13)는 거의 `answer`와 `correct` 라벨이 바뀐 것이다.
- 따라서 **행동이 맞는지는 완화 기준을 대표 지표로 보고하고**, 엄격 기준은 참고로만 둔다. 앞서 본 실행 간 변동(`answer`↔`correct` 라벨 17~21건)이 엄격 지표의 흔들림이다.
