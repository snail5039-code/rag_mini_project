## 2. retirement_pension_2025 23쪽: 부분 확정 (숫자는 정상)

대상 블록은 `blocks[3]`(table, pdfplumber)의 "적립금 규모(운용관리계약 기준)" 표다. 10개 권역 행과 계 2개 행의 금액·비중을 모두 원본과 하나씩 대조했고, **숫자가 섞인 셀은 없다.** 실제 문제는 다음 두 가지다.

| 위치 | 원본 | 추출 |
|---|---|---|
| 권역 열(1열) | 은행 / 증권 / 생보 / 손보 / 근로복지공단 / 계 | 모든 행이 빈 칸. 행이 어느 권역인지 순서로만 알 수 있음 |
| '24.12월 행의 전체 비중 | 52.3 / 24.1 / 19.0 / 3.6 / 1.1 / 100.0 | 6개 모두 빈 칸 |

참고로 증권 '25.12 개인형IRP `46,4563`은 원본 PDF에도 이렇게 인쇄돼 있다(원본 오탈자). 계산하면 464,563 근처가 맞다. 추출 오류는 아니다.

- **영향받는 문항**: ADD-RP14 (team_golden_set, source_pages [3, 23, 29]). 이 문항이 쓰는 계 행(2,289,483 / 1,399,982 / 15,812 / 1,308,757 / 5,014,034)은 정상으로 추출됐다. 다만 권역 이름이 없어 검색·답변 과정에서 "계" 행을 알아보기 어렵다.
- **수정 방법**: `blocks[3]`만 고친다. 1열에 권역 이름을 채우고 '24.12 전체 비중 6개 값을 넣으면 된다. 재추출은 필요 없다.

## 3. retirement_pension_2025 17쪽: 추출 오류 아님

17쪽 `blocks[4]`(chart, gemini_vision)의 "권역별 점유율 추이" 값은 원본 차트에 인쇄된 숫자와 모두 같다.

| 권역 | 차트 표기 '23년 / '24년 / 25년 (원본 = 추출) |
|---|---|
| 은행 | 50.9 / 51.8 / 52.3 |
| 증권 | 22.0 / 22.7 / 24.1 |
| 생명보험 | 21.6 / 20.5 / 19.0 |
| 손해보험 | 4.3 / 3.9 / 3.6 |
| 근로복지공단 | 1.2 / 1.1 / 1.1 |

4쪽 본문은 "증권사 점유율 추이: ('23년) 22.7% → ('24년) 24.1% → ('25년) 26.2%"이고, 4쪽 추출 `blocks[9]`도 같다. 23쪽 표의 '24.12 전체 비중(은행 52.3, 증권 24.1, 생보 19.0, 손보 3.6, 근로 1.1)은 차트의 "25년" 열과 정확히 같다. 17쪽 본문의 "은행 △0.3%p, 증권 +2.1%p"(52.3→52.0, 24.1→26.2)와 맞춰 봐도, **원본 차트가 한 해 이전 값('22~'24년)에 '23~'25년 라벨을 붙여 인쇄한 것**으로 보인다. 원본 문서의 불일치이지 추출 오류가 아니다.

- **영향받는 문항**: 17쪽을 근거로 쓰는 문항은 없다. 4쪽을 쓰는 문항은 ADD-RP05(03_answers, source_pages [3, 4])인데, 점유율이 아니라 ETF 비중을 다룬다.
- **수정 방법**: 추출 값은 그대로 둔다. 필요하면 `blocks[4]`에 "원본 차트 연도 라벨이 본문·붙임 표와 1년 어긋남('25년 열 = '24년말 값)"이라는 주석을 붙인다. README 후보 목록에서는 "원본 불일치"로 옮긴다.
