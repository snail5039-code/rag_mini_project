## 참고
- ADD-RP11: 비중 변화(△4.0, +0.8, +3.2)는 표의 괄호 값(%p)이다. 본문의 'IRP +30.6%p / +32.6%p'처럼 증가율에 %p를 쓴 표기가 일부 있으나 이 질문에서는 표 값 기준으로 증가율은 %로 썼다. DC는 기업형 IRP를 포함한 값이다(ADD-RP14 참고).
- ADD-RP12: 예·적금 147.8조원 = 은행 127.5(우체국 포함) + 저축은행 20.3, 147.8 + 143.5 + 37.1 + 49.7 = 378.1조원임을 PDF 16쪽 표에서 확인했다. ELB 설명은 표 각주 3).
- ADD-RP13: '5년 평균(2019~2023)'은 10쪽 각주, '2025년 연간수익률 6.47%·국민연금 19.9%·미국 12.2%·일본 12.3%'는 5쪽 본문과 각주. 보고서가 한국 6.47%를 호주와 직접 비교하지는 않는다.
- ADD-RP14: 1,399,982 + 15,812 = 1,415,794억원 ≈ 141.6조원, 2,289,483 + 1,399,982 + 15,812 + 1,308,757 = 5,014,034억원을 확인했다. 비중 27.9% + 0.3% = 28.2%(반올림). 23쪽 표는 PDF 이미지에서 직접 읽었다(박의혁 님 추출에서는 일부 행의 숫자가 섞여 있음).
- ADD-RP15: 답할 수 없는 질문. 연령(대)별 수익률 키워드가 23개 PDF 어디에도 없음을 확인했다.
- 참고(추출 오류 후보): 박의혁 님 추출의 17쪽 '권역별 점유율 추이' 차트 표는 4쪽 본문(증권 22.7%→24.1%→26.2%)과 한 칸씩 어긋나 보인다(증권 22.0/22.7/24.1). 이 값은 질문에 사용하지 않았다.
